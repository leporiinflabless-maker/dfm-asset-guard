# dfm-asset-guard · v1.0.20

## v1.0.20 更新

- **退出面板时自动停止守卫**：面板正常退出时向守卫发送退出命令（独立进程、优雅停止，几秒内结束）；
  重新打开面板会自动再次拉起守卫；
- ⚠ 注意：退出面板后，告警邮件 / 冻结能力 / 登录态保活将一并停止；需要后台常驻时请保持面板运行（可最小化）；
- 其余功能同 v1.0.19。

## v1.0.19 更新

- **稳定性修复（安全中心会话保活）**：
  - 修复「暂停监控」会导致会话保活同步停止、登录态几分钟内失效的问题（保活现与暂停无关，始终运行）；
  - 修复非登录接口下发的新令牌未落盘、可能被保活重载覆盖而失效的问题（任何响应的新令牌现在**立即写盘**）；
  - 保活重载 cookies 失败时记录日志；邮件限频与触发冷却**持久化**（守卫重启后不再重复发提醒邮件）；
- 其余功能同 v1.0.18。

## v1.0.18 更新

- **清除剩余写死的开发机路径**（全组件排查后）：
  - 命令行工具的默认采集配置（`probe` / `refresh-cookie` 等）改为 exe 同目录；
  - 守卫与插件的「根目录兜底」改为程序自身目录（不再回落 `F:\...`）；
  - 移除插件中历史遗留的 Python 启动回退（纯 C++）；
- 其余功能同 v1.0.17。

## v1.0.17 更新

  而是与显式置空一致——自动使用 `dfm-guard.exe` 同目录（自包含）；
- 即：这两个字段现在**不填 / 缺失 / 置空**行为完全一致，普通使用无需关心；

## 使用说明

> 📖 **完整操作手册见包内《操作说明.md》**（安装、菜单、设置、Cookie/登录态提醒、重新授权步骤、微信版本依赖、常见问题）。

### 1. DFMMonitor（监控面板）
- 解压到任意目录（**不要放在系统 Temp 目录**），双击 `DFMMonitor.exe`；悬浮窗/任务栏窗口显示资产、哈夫币、状态；
- **检查更新**：启动自动检查或右键菜单 →「检查更新」（更新源为本项目 Gitee 仓库）；
- 每 30 分钟播放 3 遍走马灯提示（单击窗口打开 https://mhw.pub）；
- **提醒**：未读取到小程序 Cookie / 未获取到安全中心登录态时，走马灯会滚动提醒并给出恢复指引。

### 2. dfm-guard（守卫服务）
- 复制 `service_config.example.json` 为 `service_config.json`（与 exe 同目录），填写 `email.server_token`、`email.to`；
- 双击运行或 `dfm-guard.exe run`；插件会自动拉起本服务；
- **重新授权**（安全中心登录态失效后恢复）：
  - 面板右键任一窗口 → 三角洲资产监控 → **重新授权（抓取微信登录态）**；
  - 或命令行 `dfm-guard.exe reauth`；
  - 执行后按提示在微信里打开一次「腾讯游戏安全中心」页面（打开“冻结查询”停留几秒），
    抓取完成后自动写入并恢复登录态（无需 Python/frida）；
  - ⚠ **微信版本依赖**：抓取组件适配 **微信 Windows 4.1.15**（XWeb/flue 运行时 25715）；
    官方下载：https://dldir1v6.qq.com/weixin/Universal/Windows/WeChatWin_4.1.15.exe
    其他版本可能不工作；微信升级后如抓取失效，需重新定位偏移（详见《操作说明.md》第九节）。

### 3. 组合使用
解压整包后：先启动 `DFMMonitor.exe`（插件会自动拉起 `dfm-guard.exe`），即可看到实时数据。
